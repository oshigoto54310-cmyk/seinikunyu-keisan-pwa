# 精肉 値入計算

裸原価、売価、本部費率、歩留まり、ロス率、消耗品比率から値入率と原価を計算する、端末内完結型のPWAです。外部API、ログイン、サーバーDBを使いません。

## 起動と計算テスト

Node.js 18以降を用意し、このフォルダで実行します。

```powershell
npm test
npm start
```

ブラウザーで `http://127.0.0.1:4173` を開きます。ローカル起動はオフライン動作の確認用です。Service Worker は HTTPS または localhost で動作します。

## 公開

このフォルダ内のファイルと `icons` フォルダを、HTTPSに対応した静的Webホストの公開ディレクトリへ配置してください。ビルドや環境変数は不要です。`index.html`、`manifest.webmanifest`、`service-worker.js` が同じアプリの公開パス内にあることを確認します。

GitHub Pagesを使う場合は、既存プロジェクトに手を加えず、このフォルダの中身だけで独立したリポジトリを作ります。

1. GitHubで新しいリポジトリを作り、このフォルダのファイルと `icons` をリポジトリのルートへ登録して `main` ブランチへ反映します。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** を **Deploy from a branch** にし、ブランチを `main`、フォルダを `/(root)` にして保存します。
4. Pagesの公開が完了したら `https://<ユーザー名>.github.io/<リポジトリ名>/` をスマートフォンで開き、計算画面を確認します。

GitHub Pagesを既存リポジトリで使う場合、公開元はブランチのルートまたは `/docs` を選べます。アプリファイル一式をその公開フォルダ直下に置いてください。アプリを別の静的ホストで公開する場合も、HTTPSを有効にして、ファイル一式を同じ公開パス内に置きます。

初回アクセス時にアプリ一式を端末へ保存します。一度オンラインで開いた後は、通信を切っても計算できます。本部費率と消耗品比率は初期値をそれぞれ5%、2.5%とし、共通条件を開けば後から変更できます。設定はその端末のブラウザー内に保存され、別端末や別ブラウザーとは共有されません。ブラウザーのサイトデータを消すと設定も消えます。

## ホーム画面への追加

- **iPhone**：Safariで公開URLを開き、共有ボタンから「ホーム画面に追加」を選びます。「Webアプリとして開く」が表示された場合はオンにして追加します。追加後はホーム画面のアイコンから起動できます。
- **Android**：Chromeで公開URLを開き、メニューの「アプリをインストール」または「ホーム画面に追加」を選びます。表示される名称はChromeのバージョンにより異なる場合があります。

公式手順：[GitHub Pagesの公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)、[iPhone Safari](https://support.apple.com/guide/iphone/iph42ab2f3a7/ios)、[Android Chrome](https://support.google.com/chrome/answer/9658361?co=GENIE.Platform%3DAndroid&hl=ja)

## 計算式

1. 本部費加算後原価 = 裸原価 × (1 + 本部費率 / 100)
2. 歩留後原価 = 本部費加算後原価 ÷ (歩留まり / 100)
3. ロス反映後原価 = 歩留後原価 ÷ (1 − ロス率 / 100)
4. 完成品原価 = ロス反映後原価 × (1 + 消耗品比率 / 100)
5. 値入高 = 売価 − 完成品原価
6. 値入率 = 値入高 ÷ 売価 × 100

ロス率は商品ごとに入力し、初期値は0%です。歩留まりで原価を補正した後、ロス率を反映して完成品原価を計算します。画面表示では金額を小数第1位まで、値入率を小数第1位まで表示します。計算自体は丸めずに行います。裸原価・売価・歩留まりが空欄の場合や、売価0円、歩留まり0%、100%以上のロス率、負の数は計算せず入力エラーを表示します。
