# 精肉 値入計算PWA デモ版

精肉商品の値入率と原価を、その場で計算する順計算のみのデモ版です。外部API、ログイン、サーバーDBを使いません。

デモでは、目標値入率からの逆算（必要売価・許容原価）は使えません。この機能は製品版に含まれます。

## 起動とテスト

Node.js 18以降を用意し、このフォルダで実行します。

```powershell
npm test
npm start
```

ブラウザーで `http://127.0.0.1:4173` を開きます。Service Worker は HTTPS または localhost で動作します。一度オンラインで開けば、アプリ一式が端末に保存され、オフラインでも計算できます。

## 計算式

1. 本部費加算後原価 = 裸原価 × (1 + 本部費率 / 100)
2. 歩留後原価 = 本部費加算後原価 ÷ (歩留まり / 100)
3. 消耗品加算後 = 歩留後原価 × (1 + 消耗品比率 / 100)
4. ロス反映後原価 = 消耗品加算後 ÷ (1 − ロス率 / 100)
5. 完成品原価 = ロス反映後原価
6. 値入高 = 売価 − 完成品原価
7. 値入率 = 値入高 ÷ 売価 × 100

中間値は丸めずに計算し、画面表示時のみ小数第1位に丸めます。初期値は歩留まり100%、ロス率0%、本部費率5%、消耗品比率2.5%です。裸原価・売価は0円より大きく、歩留まりは0%より大きく100%以下、ロス率・本部費率・消耗品比率は0%以上100%未満の値を受け付けます。

本部費率と消耗品比率だけを端末内に保存します。商品条件は保存しません。デモ版の保存キーは `demo_niku-margin-settings-v1`、Service Workerキャッシュは `demo_niku-margin-v1` です。Service Worker の有効化時に、同一オリジン上の他のキャッシュを削除してから新しいキャッシュを使用します。
